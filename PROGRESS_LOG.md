## Запись от 2026-09-29 12:11 (+04) — v1.2: переработка TUI под утверждённый макет

### Что сделано

1. **Макет v1.2 (16:9, три панели).** `TabbedContent`, `Header`, `Footer`
   удалены; `VictusScreen` → `#shell` (border-title) → `KbdTab` из трёх панелей:
   - **PRESETS** (width 20) — вертикальный список 50 цветов, лейбл
     `имя(10) [■]` с цветным квадратом, монохромный скроллбар;
   - **COLOR PICKER** (1fr) — три ASCII-слайдера `Hue/Saturation/Brightness`,
     квадратный предпросмотр `#preview` **20×10 ячеек = 244×246 px** (ячейка
     12.2×24.65 → 1:1), ридауты `H/S/V/Hex`, кнопки `[ Apply ] [ Copy HEX ]
     [ Save Preset ]` **прижаты к низу панели**;
   - **LIGHTING EFFECTS** (36) — режимы `[ ] Static [*] Cycle [ ] Fade`,
     `Custom Effect Creator` с живой синусоидой, `Effect Speed [===]`,
     `[ Start ] [ Stop ]` (низ = `y=30..33`, совпадает с кнопками пикера).
2. **`bin/tui/slider.py`:** `AsciiSlider` — прогресс-бар `[====]`,
   `ALLOW_SELECT=False` (клик/драг/колесо/←→/Home/End двигают ползунок, а не
   выделяют текст); `SineWave` — **связной** рисунок (между столбцами
   дорисовываются `│`, глифы из `RAMP`, 8 подуровней на ячейку), период
   `ширина/1.5`, амплитуда `0.8·mid`, тик 0.12 с.
3. **`bin/tui/kbd_tab.py`:** панели собираются генераторами-хелперами
   (сами панели yield-ит только `compose()` — иначе `Widget.__enter__` +
   `textual/compose.py` дают дубль); `RowButton(Button)` — снимает встроенный
   `line-pad: 1` и хардкод `+2` в `Button.get_content_width`, из-за которого
   ряд режимов переполнял панель (37 > 32 → теперь 31 ≤ 32) и пресеты теряли
   `]`; `SavePresetScreen` перенесён сюда (иначе циклический импорт).
4. **Найденные и починенные баги:**
   - `push_screen(..., wait_for_dismiss=True)` в Textual 8 падает с
     `NoActiveWorker` → `@work(exclusive=True)` (кнопка «Save Preset»);
   - метод `_name()` перекрывался атрибутом `Widget._name = None` →
     `TypeError: 'NoneType' object is not callable` → `_entered_name()`;
   - `Static.update(f"Hex: [{hex}]")` парсился Rich-разметкой и **терял
     значение** → `update(Text(...))` (там же в модалке);
   - `line-pad: 0` **запрещён парсером Textual** (нулевые integer-значения
     отвергаются) → значение ставится программно в `RowButton`;
   - статус на старте пуст (в макете), центрирование строки статуса через
     `#status-flow { width: 100% }` (иначе сдвиг на 4 колонки из-за `auto`);
   - нижние границы панелей выровнены, пустых «провалов» нет.
5. **Локали:** добавлены ключи макета `tui.sec_presets/sec_picker/sec_effects/
   sec_creator`, `tui.btn_apply/copy_hex/save_preset/start/stop/save/cancel`,
   `tui.mode_static/cycle/fade`, `tui.lab_hue/sat/val`, `tui.color_tag`,
   `tui.speed_label`, `tui.app_title`, `tui.save_title` и др. Метки панелей и
   кнопок **намеренно по-английски** (по макету), статусные/ошибочные строки
   остаются локализованными. ru/en синхронны: 90/90 ключей, все `t()` найдены.
6. **Проверки:** геометрия headless 128×36 (регионы всех виджетов, выравнивание
   кнопок, ширина лейблов ≤ доступной), смоук-тест **12/12 PASS** (клик
   пресета → `#0000ff`, 3 режима, copy/apply/start/stop со статусами, модалка
   сохранения → реальная запись `testcolor` в `config/colors.conf`, запись
   откатлена), `python3 -m compileall bin` OK.

### Изменённые файлы
- `bin/tui/screens.py` — весь CSS макета v1.2 (панели, кнопки, статус, модалка, скроллбар, `#power`)
- `bin/tui/kbd_tab.py` — композиция трёх панелей, `RowButton`, `SavePresetScreen`, воркер модалки
- `bin/tui/slider.py` — `AsciiSlider`/`SineWave` (связная синусоида, `RAMP` на 8 глифов)
- `locales/ru.json`, `locales/en.json` — новые ключи `tui.*` (метки макета)

### Костыли / нюансы / ошибки
- **`RowButton`** — костыль под два ограничения Textual 8: CSS-парсер не
  принимает `line-pad: 0`, а `Button.get_content_width` жёстко возвращает
  `len(label) + 2`. Программное `styles.line_pad = 0` переживает
  `stylesheet.apply` (проверено), т.к. `DEFAULT_CSS` виджета применяется один
  раз при регистрации.
- **SVG-экспорт** даёт ячейку 12.2×24.65 (1:2); конвертация с жёстким
  `-w 1536 -h 432` сжимает строки вдвое и превью выглядит прямоугольником —
  сравнивать пропорции только в натуральном размере: `rsvg-convert -w 1580`.
- Хелперы `_presets_panel/_color_panel/_effects_panel` **не должны** сами
  yield-ить панель: `with panel:` уже регистрирует её через `__enter__`.
- В локалях остались 18 старых ключей `tui.*` от вкладки v1.1-alpha
  (`tui.apply`, `tui.hue`, `tui.tab_kbd`, …) — не используются, оставлены;
  `tui.need_textual` используется в `bin/victus_tui`.

## Как добавлять новую запись (шаблон)

```markdown
## Запись от ГГГГ-ММ-ДД ЧЧ:ММ (+04)

### Что сделано
- пункт 1 (что именно, какая команда/функция)

### Изменённые файлы
- `путь/к/файлу` — что изменилось

### Костыли / нюансы / ошибки
- честно: что пошло не так, что сделано костылём, что не проверено

### Следующий шаг (план)
1. точное действие
2. что спросить у пользователя
```

**Правила записи:**
- одна запись = один подтверждённый пользователем шаг;
- время — местное, с таймзоной;
- «Следующий шаг» пишется так, чтобы его мог выполнить **чужой** агент;
- не удалять старые записи — они и есть история.
