## Запись от 2026-10-01 19:02 (+04) — SMART: авария без бешеного прыжка + пульс в лог

### Повод

Голосовое (по смыслу): SMART «в какой-то момент решает начать крутить
вертушки очень громко», «вентиляторы начинают крутиться в рандомный
момент при длительном состоянии — не в сон-режиме, а именно в активном
(фильм/видео/работа)», «в моменте просто сходит с ума и начинает крутить
к бешеному — это самое исправь». Условия: **тонировки не трогать**
(presets.json), улучшения обсуждать с пользователем отдельно.

### Как устроен режим (раскладка кода)

- режим запоминается в `state/fan_mode.json` (на момент сессии — `auto`),
  автопилот: `vertil_tab._tick` (1 с, идёт даже со скрытой вкладки) →
  `vertil_core.snapshot()` → `_smart_step` → `fanlib.Smart.update(snap, dt)`
  → запись `set-pwm` через `sudo -n victus-kbd fans` (root только на запись);
  закрытие TUI при автопилоте → `vertil_core.shutdown()` держит hold 180;
- контроллер `fanlib.Smart` из `presets.smart`: slope dT/dt (окно 6 с
  CPU/GPU, 15 с VRM) → экстраполяция horizon 8 с → score по полосам
  (cpu 52..90, gpu 50..86, vrm 62..88, веса каналов) → цель floor 60 ..
  ceil 255 → slew: вверх `rise_pwm_per_s`=8, вниз 3, deadband 2;
  VRM-канал с весом 0.85 достаёт CPU-fan; кепы `caps.enabled=false`;
- авария (`emergency`: cpu 93 / gpu 83): **было** — мгновенный
  `p1=p2=255` в один тик в обход deadband, обе вертушки на максимум
  через ~1 с; UI-чип `!!` загорался с первого горячего снимка.

### Диагностика: два разных механизма

1. **«В моменте сходит с ума» = EMERGENCY.** Один горячий снимок
   (всплеск браузера, бурст декодера, индексация) → мгновенный 255 на
   обоих вентиляторах; после остывания спад 3 PWM/с ≈ минута шума.

же свет, который демон тут же возвращал на полную. TUI стартует демон
через `core.ensure_daemon()` (`screens.py:610`) — он проверял только
живость сокета, **версию не сверял**, и `victusd.VERSION = "1.0"`.

- `bin/tui/core.py`: константа `DAEMON_VERSION = "1.1"`, метод
  `Engine.hello()` (полный ответ ping: version/pid/state, рядом с
  `ping()` = bool), `ensure_daemon`: живой демон отвечает, но версия
  не совпадает → `request("quit")` → ждать ≤3 с, пока ping упадёт или
  сокет исчезнет → `os.unlink` → `spawn_daemon()` → ждать ping ≤4 с;
